客户定义方向与标准，Eastlink 负责开发与执行落地

① 一条主线 · 四个阶段

Stage 1Brief → 设计定稿Brief 接收 → 结构化拆解 → 需求包 · SKU 清单 → 产品提案（成熟结构复用 / 新结构验证）→ 设计协同交付物：SKU 开发清单 + 定稿设计
Stage 2规格 + 质量前置规格与质量：每 SKU 一份 PSF 规格书 + PPA 测试要求，与定稿同步完成交付物：可投产规格
Stage 3打样 → 比价 → 定商多维度匹配 → 打样 → 比价（同规格同口径）→ 比样定商 → 确认合作交付物：确认的合作供应商与基准样
Stage 4交付与包装金样 / FS 确认 → 包装结构与刀线 → 四项就绪门全绿放行交付物：可投产的完整交付包（P2）

② 一句分工

客户提出 Brief 需求 · 提供品牌规范细则 · 确认设计稿定稿
Eastlink拆解 · 设计 · 规格与质量 · 匹配打样 · 比价定商 · 质量放行

变化点：以前客户要出设计稿、写规格、定测试要求、逐轮提意见；现在只做方向、标准、确认三件事，中间的执行性工作整体前移到平台。

③ 三条边界

  • 流转最小单位是需求包；SKU 是包内跟踪维度——设计出稿、规格书、打样评分、质量档案都到 SKU。
  • 客户只确认一次：设计稿定稿；定商由 Eastlink 内审确定后同步结果，不做二次确认。
  • 平台管到定商与质量放行；大货下单、订单跟进、包装刀线属 P2，不在本轮框架内。

④ 待业务拍板的五件事（框架级，其余都是实现细节）

  1. 流转最小单位需求包还是 SKU？有没有"一个需求包分给两家"的情况？
  2. 承接边界定商即结束，还是要管到金样、包装、大货？
  3. 硬性门槛一票否决项到底有哪些？（现假设：准入 / 品类 / 工艺三条固定）
  4. 质量前置测试要求真能与设计定稿同步定义吗？（这是本方案最强的主张）
  5. 内审归属谁审——业务员还是主管？定商结果以什么形式同步客户？

分期：P1（本 Demo）三份主数据 + 拆解 + 匹配 + 设计协同 + 质量控制塔 + 角色权限；P2 真实后端与客户 / 供应商门户、订单跟进；P3 匹配模型自学习与 AI 拆解。

Why This Platform现状六个卡点 → 平台怎么接为什么要做这个平台：六个现状问题与对应解法
① 设计稿不可直接投产AI 稿 / 文字错误 / 结构与实际产品不符，供应商反复检查修改。设计协同：逐 SKU 出稿 + 内审校验
② 设计与规格对不上设计、尺寸、材质信息不一致，来回澄清。标准 PSF：规格书由平台生成，客户只确认
③ 测试要求来得太晚样品出来后才明确测试要求，后期改规格造成返工。PPA 前置：质量要求随设计定稿同步定义
④ 色样多轮返工不同供应商、色样、材料间缺统一标准，重复打样。材料与色彩资产库：Pantone 色卡 + ΔE 验收口径
⑤ 意见多但难落地Comment 很细但缺产品与生产端经验，且不同人意见不一致。审核中心：意见留痕 · 单一决策流
⑥ 人员变动知识断层新人加入 / 休假 / 离职后，项目知识与判断标准无法延续。组织知识库：标准与档案沉淀，不依赖个人

问题不在于投入不够，而在于太多执行性工作压在客户侧——而设计、规格、测试、打样恰恰需要大量产品 / 材料 / 工艺 / 制造知识，这正是平台方最擅长的。Right Work, Right Team.

对应第 ⑥ 条：知识沉淀在平台而不是个人

品牌智能档案材料与色彩资产库 合规验厂标准PSF / PPA 标准模板 SKU 结构沉淀（刀线库 P2）审核与流转全程留痕

人员变动不再带走项目知识，新人接手即有完整上下文。

需求包状态机（导图主线在系统里的实际状态）：设计中 → 待选打样候选 → 打样名单内审 → 打样中 → 定商建议内审 → 已确认合作（结果同步客户）；设计定稿自动进入匹配，内审可退回比样 / 换选并记录原因。需求包内拆到 SKU：设计出稿、规格书、打样评分、质量档案都按 SKU 跟踪。

Matching Model匹配模型：硬性门槛 + 加权排序两层三条固定门槛 + 两个可切换档位 + 8 维权重
硬性门槛档位说明
准入状态固定硬性必须"已准入 / 合作中"，否则不进入候选
品类覆盖固定硬性主营或兼营须覆盖需求品类
工艺全覆盖固定硬性缺任一需求工艺即排除——做不了就是做不了，不存在"工艺 60 分"
认证全齐可切换（默认评分）打样期间可补办认证；对严格需求可一键切为硬性排除
客户验厂红线可切换（默认警示）打样可并行补审、下单前须完成；可切为硬性排除。正式版按需求包字段级配置

过了门槛之后按 8 维加权排序：品类专精 20 / 认证覆盖 17 / 质量表现 15 / 交付可靠 12 / 价格竞争力 12 / 产能匹配 9 / 客户经验 8 / 风险等级 7 —— 数据全部取自供应商档案字段，权重可拖滑杆实时重排（详见匹配工作台）。

为什么分两层工艺这类是"能不能做"的问题，属于门槛；质量价格交期是"谁做得更好"的问题，属于排序。混在一起打分会把"做不了"的供应商排进名单。
门槛开关认证与验厂红线支持现场切换硬性 / 评分档位，候选实时掉入漏斗排除名单——可当场演示两种口径的差别。
比价与比样候选按同一份定稿与规格出样并报价；质量 / 工艺还原 / 报价按 SKU 逐项评分，综合分为各 SKU 均值 → 生成定商建议。同规格同口径，价格才有可比性。
